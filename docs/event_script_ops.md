# Event script opcodes (`src/maps/scripts/*.json`)

## File shapes (FEATURE-MAP-043 + legacy)

**Canonical (editor / new files):** `map` (string, map id for tooling), `version`, `script_1` as an **array of one-key objects** (each object has exactly one property: the opcode string → args object). Optional `script_2` may be an empty array reserved for future multi-block scripts. The C++ runner **executes `script_1` only** for now (normalized to internal steps).

```json
{
  "version": 1,
  "map": "sample_room",
  "script_1": [
    { "show_message": { "text": "Hello" } },
    { "wait_frames": { "n": 30 } }
  ],
  "script_2": []
}
```

**Subflows (FEATURE-MAP-074):** an optional `subflows` object maps a subflow name → an array of one-key step objects (same shape as `script_1`). Subflows are callable from any flow in the same file via `call_subflow`, run on a dedicated call frame with their own scratch variables, and return to the caller when they finish. Reusable cross-map "custom connectors" live as standalone files under `src/maps/scripts/_library/<name>.json` (their `script_1` is the subflow body) and are loaded on demand by `Game::loadLibrarySubflow_`.

```json
{
  "version": 1,
  "map": "sample_room",
  "script_1": [
    { "call_subflow": { "name": "greet", "vars": { "who": "Red" } } },
    { "show_message": { "text": "Done" } }
  ],
  "subflows": {
    "greet": [ { "show_message": { "text": "Hello!" } } ]
  }
}
```

**Legacy:** root may instead carry an `actions` array of `{ "op": "<opcode>", "args": { } }`. `ScriptRuntime::loadDocument` uses **normalized `script_1` when it produces at least one step**; otherwise it falls back to `actions`.

**Alternate:** `script_1` may be a single JSON object whose keys are opcodes (insertion order); duplicate opcodes are not representable—prefer the array form.

Status: **implemented** (dispatch in `src/op.cpp`, document normalization in `src/script_engine.cpp`) | **stub** (logged + on-screen debug line only).

## Opcode inventory (FEATURE-MAP-044 + FEATURE-MAP-048)

The **ordered** opcode set consumed by `tools/event_script_schema.py` (map editor palette and defaults) is `CPP_SCRIPT_OPS_ORDERED` in **`tools/event_script_ops_generated.py`**, regenerated by **`python3 docs/cursor_helper_scripts/extract_map_script_ops.py`** from `if (op == "...")` branches in **`src/op.cpp`** (first-seen order). Labels, descriptions, default args, `stub`/`implemented` flags, per-field help, **`category`** (palette grouping), and **`required_params`** (documentation: mandatory fields) live in **`tools/event_script_op_meta.json`**; the extractor **fails** if C++ and meta disagree. The tables below remain a human-readable summary; for tooling, treat **generated list + meta** as authoritative.

## Implemented opcodes (map viewer)

| op | args | Notes |
|----|------|--------|
| `end_script` | — | Stops interpreter; unlocks if locked. |
| `lock_player` | — | Blocks WASD map movement until `unlock_player` or script end. |
| `unlock_player` | — | Re-enables movement. |
| `wait_frames` | `n` (int) | Yields for `n` frames (decremented before each opcode step). |
| `show_message` | `text` (string) | Yields until **Q** or **Space** (map viewer). |
| `close_message` | — | Clears message overlay. |
| `set_flag` | `name` (string) | **Persistent** boolean flag (FEATURE-MAP-072). Written through `GameState` (`save/game_state.json`) when callbacks are wired; falls back to a runtime-only map in unit tests. |
| `clear_flag` | `name` | **Persistent** (see `set_flag`). |
| `unless_flag` | `name`, `skip` (int) | If flag false, skip next `skip` actions (relative). |
| `if_flag` | `name`, `skip` (auto) | **Block opener.** Runs the actions up to the matching `end_if` only when `name` is set. `skip` (body length) is stamped automatically by `ScriptRuntime::resolveControlFlow` on load — do not author it by hand. |
| `end_if` | — | **Block terminator** for `if_flag`. Managed by the block editor. |
| `repeat` | `n` (int), `skip` (auto) | **Block opener.** Loops the actions up to the matching `end_repeat` `n` times (`n<=0` skips the block). `skip` auto-stamped on load. |
| `end_repeat` | — | **Block terminator** for `repeat`. Jumps back to the body start until the loop drains. |
| `warp_player` | `mapId`, `x`, `y` | If `mapId` is in `src/maps/world_layout.json`, loads **Overworld** at map-local `(x,y)` on that instance; else standalone `src/maps/{mapId}.json`. Ends script. |
| `set_player_facing` | `dir` | Sets trainer facing row (`up`/`down`/`left`/`right`, also north/south/east/west aliases). |
| `walk_to_coords` | `direction` (str), `steps` (int), `faceFirst` (bool, default `true`) | **FEATURE-MAP-071 — Rail movement. Blocking:** moves the player exactly `steps` tile strides along `direction` (cardinal: up/down/left/right, also north/south/east/west, n/s/e/w). Movement is strictly along that rail axis. If `faceFirst` is `true` (default) the player turns to face `direction` before the first step. `steps:0` with `faceFirst:true` produces a turn-only with no movement. Blocked footprint ends the opcode early. WASD ignored while active. |
| `run_to_coords` | `direction`, `steps`, `faceFirst` | **FEATURE-MAP-071.** Same rail movement as `walk_to_coords` with faster animation timing (half per-segment frame duration) for the opcode's duration. |
| `face_north` | — | Sets facing north (up); instant. |
| `face_south` | — | Sets facing south (down). |
| `face_east` | — | Sets facing east (right). |
| `face_west` | — | Sets facing west (left). |
| `move_camera` | `direction`, `steps`, `speed` (optional int) | **Blocking:** pans view by shifting script camera offset one tile per step (`direction`: north/south/east/west or up/down/left/right). `speed` = engine frames to wait between steps (0 = one step per frame). Offsets reset when the script ends or map UI reloads. |
| `camera_zoom_in` | — | Multiplies map/overworld tile draw scale (clamped). |
| `camera_zoom_out` | — | Divides draw scale (clamped). |
| `camera_follow_player` | — | Clears scripted camera tile offset and active `move_camera` pan state, then re-syncs camera to follow the player (map or overworld). Does **not** reset `camera_zoom_in` / `camera_zoom_out` scale. |
| `call_subflow` | `name` (string), `vars` (object, optional) | **FEATURE-MAP-074.** Calls the named in-file subflow (or `_library/<name>.json`) like a method. `vars` seeds the callee's scratch variables by name. Pushes a `ScriptCallFrame`; execution returns to the next caller step when the subflow ends. Guarded by `ScriptRuntime::kMaxCallDepth` (32) against runaway recursion. |
| `stop_script` | — | **FEATURE-MAP-075.** Ends the entire script immediately (unwinds the whole call stack), regardless of nesting or call depth. |
| `goto` | `label` (string) | **FEATURE-MAP-075.** Jumps to `label {name}` **within the current flow**. The editor offers a dropdown of labels declared in that flow. |
| `label` | `name` (string) | **FEATURE-MAP-075.** No-op marker; a `goto` target. Indexed per-flow by `ScriptRuntime::rebuildLabels_`. |
| `comment` | `text` (string) | **FEATURE-MAP-076.** No-op; documentation only. |
| `region` | `name` (string) | **FEATURE-MAP-076.** No-op block opener for visual grouping; collapsible/renamable/nestable in the editor. |
| `end_region` | — | **FEATURE-MAP-076.** Block terminator for `region`. |
| `set_var` | `name` (string), `value` (int/string/bool) | **FEATURE-MAP-077.** Sets a per-flow scratch variable on the active call frame. **Not persisted** (cleared on script end). |
| `if_var` | `name`, `op` (`==`,`!=`,`<`,`>`), `value`, `skip` (auto) | **FEATURE-MAP-077. Block opener.** Runs the body up to the matching `end_if_var` only when the comparison holds. `skip` auto-stamped on load (same mechanism as `if_flag`). |
| `end_if_var` | — | **FEATURE-MAP-077.** Block terminator for `if_var`. |
| `set_route_music` | `track` (string), `fadeMs` (int, default 0) | **FEATURE-MAP-087.** Starts looping background music from `src/audio/<track>.ogg`. If `fadeMs > 0` the previous track fades out while the new one fades in. No-op when `track` is empty. Requires SDL2_mixer build flag. |
| `play_music_once` | `track` (string) | **FEATURE-MAP-087.** Plays `src/audio/<track>.ogg` once (no loop). No-op when `track` is empty. |
| `start_trainer_battle` | `battleId` (string, optional), `outcomeMode` (string, default `"normal"`), `music` (string, optional), `background` (string, optional), `trainers` (array, optional), `scriptedLossTurns` (int, optional), `lossWarp` (`{mapId, x, y}`, optional) | **FEATURE-MAP-088.** Starts a scripted trainer battle; script yields until the battle ends. If `battleId` is set the library definition from `_library/battles/<battleId>.json` is the base; inline args override. Outcome modes: `"normal"` — loss warps + aborts script, win continues; `"scripted_loss"` — always warp; `"scripted_win"` — script continues regardless of result. Loss warp priority: opcode `lossWarp` > map `healPoint` > global default. |

## Chaining movement (FEATURE-MAP-071)

`walk_to_coords` and `run_to_coords` accept a `faceFirst` bool (default `true`) so you can combine facing and walking in any order:

**Turn only** (via walk opcode, steps:0):
```json
{ "walk_to_coords": { "direction": "west", "steps": 0, "faceFirst": true } }
```

**Turn-then-walk:**
```json
{ "walk_to_coords": { "direction": "south", "steps": 4, "faceFirst": true } }
```

**Walk-then-turn** (face after walk using an explicit face_*):
```json
{ "walk_to_coords": { "direction": "west", "steps": 3, "faceFirst": false } },
{ "face_south": {} }
```

**Walk-only** (player already facing correct direction from a prior `face_*`):
```json
{ "face_west": {} },
{ "walk_to_coords": { "direction": "west", "steps": 3, "faceFirst": false } }
```

Multiple `walk_to_coords` blocks chain freely since each opcode advances `pc` only when it finishes.

## Control flow / nesting (FEATURE-MAP-068)

`if_flag`/`end_if` and `repeat`/`end_repeat` are **block** opcodes that nest. On disk they remain part of the flat `script_1` array (opener, body actions, terminator). The block editor and `tools/event_script_schema.py` convert between this flat form and a nested tree:

- `steps_to_tree(steps)` — parse flat steps into nested nodes (`if_flag`/`repeat` gain a `children` list; terminators are implicit).
- `tree_to_steps(tree)` — flatten back, re-emitting terminator markers; `args.skip` is **not** written (the engine computes it).
- `validate_balanced(steps)` — verify openers/terminators are balanced and correctly nested.

At runtime, `ScriptRuntime::resolveControlFlow` (in `src/script_engine.cpp`) stack-pairs openers with terminators and stamps `args.skip` = body length. `if_flag` skips the body when its flag is false (same relative-jump mechanism as `unless_flag`); `repeat` pushes a `ScriptLoopFrame` onto `ScriptRuntime::loopStack` and `end_repeat` jumps back to the body start until the iteration count drains. Loops nest via the stack. `docs/cursor_helper_scripts/validate_map_events.py` reports unbalanced blocks as errors.

`if_var`/`end_if_var` (FEATURE-MAP-077) and `region`/`end_region` (FEATURE-MAP-076) are additional balanced block pairs handled by the same opener/terminator machinery (`resolveControlFlow`, `validate_balanced`, `_script_block_error`). `if_var` compares the active frame's scratch variable against `value` using `op` (`==`,`!=`,`<`,`>`); `region`/`end_region` are pure no-ops at runtime.

## Subflows, variables & flow control (FEATURE-MAP-074/075/077)

- **Flows & call stack.** `ScriptRuntime` holds `flows` (`main` + named subflows), an `activeFlow`, and a `callStack` of `ScriptCallFrame`. `call_subflow` pushes the caller's resume context and switches to the callee; `stop_script` clears the whole stack; reaching a flow's end pops back to the caller (`returnFromCall`). `kMaxCallDepth = 32` guards recursion.
- **Scratch variables.** `vars` live on the active frame and are typed (int/string/bool). `call_subflow`'s `vars` object seeds the callee frame by name. Variables are **never persisted** (distinct from flags).
- **Labels.** `rebuildLabels_` indexes `label` positions **per flow**; `goto` resolves only within the current flow. The editor surfaces these as a dropdown.
- **Persistent flags via callbacks.** Flag opcodes call `ScriptRuntime::readFlag`/`writeFlag`, which route through `onReadFlag`/`onWriteFlag` into `GameState` (FEATURE-MAP-072) when wired by `src/map_view.cpp`; otherwise a local map is used (tests).
- **Library connectors.** `onLoadLibrarySubflow` lets `call_subflow` resolve a name not defined in-file to `src/maps/scripts/_library/<name>.json` (FEATURE-MAP-073).

## Event triggers (FEATURE-MAP-078)

A map `events[]` entry may carry an optional `trigger` object selecting **when** its script fires:

| `trigger.type` | Fires when |
|----------------|-----------|
| `interact` (default) | Player faces the event and presses interact. `interact` events are **solid** (block their 2×2 footprint) so the player bumps into them. |
| `step_on` | Player finishes a walk onto a tile in the event footprint. |
| `on_map_enter` | The map finishes loading (fires once while idle). |
| `on_condition` | A flag condition becomes satisfied while idle. |

Related optional fields on the event:

- **`trigger.condition`:** `{ "flag": "<name>", "set": true|false }` — run-gate evaluated by `Game::mapEventRunConditionOk_`.
- **`clearedFlag`:** name of the per-event "already ran" flag. Auto-derived if omitted; gates re-firing via `Game::mapEventClearedGate_` and is set on completion.
- **`onComplete`:** `{ "setFlags": [..], "clearFlags": [..] }` applied by `Game::applyMapScriptCompletion_` when the script finishes (in addition to setting `clearedFlag`).

## Stub (unregistered opcodes)

Any opcode string not listed above is treated as **stub**: stderr log + `Script stub: <op>` overlay line when no map-viewer handler applies.

Candidate future ops (names stable for tooling): `add_var`, `start_wild_battle`, `play_sfx`, `fade_out`, `fade_in`, `give_item`, `take_item`, `heal_party`, …

## Validation

Run `python3 docs/cursor_helper_scripts/validate_map_events.py` to check map `events[]` anchors (2×2 in bounds, no overlap), script file presence under `src/maps/`, script JSON readability, optional **warnings** when a script file has no non-empty `script_1` or `actions`, `sprite.frame` within the declared sheet grid (`sheetColumns`×`sheetRows`, default 4×4 for `kind: character`), and optional **`sprite.facing`** for characters (direction aliases, FEATURE-MAP-049).

Additional checks (FEATURE-MAP-074/075/076/078): block balancing is verified across the **main flow and all in-file subflows** (`_script_block_error`); `goto` targets must name a `label` in the **same flow** and `call_subflow` must reference an in-file subflow or an existing `_library/<name>.json` (`_script_reference_errors`); event `trigger.type`, `trigger.condition`, `clearedFlag`, and `onComplete.setFlags`/`clearFlags` shapes are validated (`_validate_event_trigger`).

## Editor context menu config (FEATURE-MAP-046)

The map editor stores optional UI settings beside `keys` in **`tools/map_editor_config.json`** under **`eventScriptEditor`**:

| Field | Type | Meaning |
|-------|------|--------|
| `showDocumentationPane` | boolean | When false, the script modal hides the right-hand documentation column (two-column layout). Default true if omitted. |
| `panelWidth` | int (optional) | Persisted script modal width in pixels (clamped at runtime). FEATURE-MAP-049. |
| `panelBodyHeight` | int (optional) | Persisted height of the modal body region above the footer (clamped). FEATURE-MAP-049. |
| `opcodePaletteSort` | string | `source` (C++ order), `alpha`, or `category`. FEATURE-MAP-049. |
| `contextMenu` | array | Root nodes of the RMB menu on the step list. Omitted or invalid → built-in default tree (row ops + “Add step” submenu + “Rename script”). |

Each menu node is an object:

- **`type`:** `"action"` or `"submenu"` (default `action`).
- **`label`:** string shown in the menu (wrapped to panel width).
- **`when`:** optional visibility — `"always"` (default), `"row"` (only when RMB was on a step row), `"no_row"` (only when RMB was on empty list area).
- **Actions** also require **`id`:** a stable string from the table below.
- **Submenus** require **`children`:** array of nested nodes.

**Action ids** (validated against opcodes from `tools/event_script_schema.py` for `add:*`):

| `id` | Behavior |
|------|----------|
| `step:delete` | Delete the row under the cursor (requires row). |
| `step:copy` | Copy step to internal clipboard (requires row). |
| `step:duplicate` | Duplicate step after itself (requires row). |
| `step:paste_after` | Paste clipboard after row (requires row + clipboard). |
| `add:<opcode>` | Insert a new step with default args; `<opcode>` must exist in the editor opcode list. |
| `rename_script` | Opens the current event’s script JSON externally (same as workspace “Open script JSON”). |

If you provide a **custom** `eventScriptEditor.contextMenu` in `tools/map_editor_config.json`, you must add an action with `id` **`add:<opcode>`** for every opcode you want in the menu; the default tree is built from the full `EVENT_ACTION_DEFS` list automatically when `contextMenu` is omitted or invalid.

Implementation: **`tools/event_script_ctx_menu.py`** (validation, filtering, cascade layout). Automated checks: `python3 -m unittest discover tests -v` (`tests/test_event_script_ctx_menu.py`).
